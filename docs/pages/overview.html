gander overview

What gander does

gander turns jj diffs into durable, guided, actionable review sessions for humans and agents. Review locally, keep your state, leave action-tagged comments, guide readers through intent, and export a shareable artifact without handing your workflow to a forge.

Install / downloadSource repository

In motion

At a glance

Review sessions

Durable viewed-state, comments, tasks, and walkthroughs survive across TUI, CLI, and agent turns.

Guided walkthroughs

Author durable steps with Y, open the panel with W, toggle Focus with Z, and follow Spotlights with Alt-N/Alt-P in the normal stream.

Action-tagged comments & tasks

Cycle actions with a/K, triage work in the X tasks popup, and make review feedback executable.

Agent collaboration

MCP tools mirror the CLI, and @ summons an agent into the same local review context.

Scriptable CLI

Reviews, comments, tasks, walkthroughs, files, and hunks all have JSON-friendly commands.

Shareable HTML exports

gander export html renders a self-contained dark review page ready to hand to a teammate.

The workflow

01 Self-review before sharing

Create a review, mark files viewed, and leave yourself notes while intent is fresh.

gander reviews create --title "Self-review parser cleanup"
    
02 Review an agent's change
Tag feedback as fixes, then let the agent list, complete, and cite those tasks.
gander comments add --path src/parser.rs --line 42 --kind issue --action fix
    
03 Onboard a teammate
Build a guided path through the change and export a review they can read anywhere.
gander walkthrough add-step --file src/web_export.rs --line 1 \
  --title "Start with the exported artifact"
