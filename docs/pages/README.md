# Published pages sources

These self-contained HTML files are copied verbatim into the published
averagechris.srht.site pages for gander (see `docs/release.md`; the site
repo's `refresh-pages` job and the legacy `build-pages` flake app both copy
them without regeneration):

- `overview.html` — hand-written product tour.
- `example.html` — a **historical exported-review fixture**: a real `gander
  export html` artifact captured from a past development review. It is not
  regenerated by any script, and its embedded diff/help text predates the
  M18/M19 attention-map redesign (it still shows removed surfaces such as the
  `T` zen briefing and `S` agent review chunks; see `docs/attention.md` for
  the current model). Treat it as a sample of the export format, not current
  keybindings or UI vocabulary. Replacing it means exporting a fresh review
  with the current binary (`gander export html`), not editing the HTML.
- `tour.html`, `sample-review.html` — redirect stubs kept for old links.
